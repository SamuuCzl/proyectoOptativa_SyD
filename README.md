# SyD Wear

Tienda online de ropa casual desarrollada para el modulo
de Programacion Web Avanzada de 2º DAW.

## Integrantes - Pareja 8

- Samuel Chillon Martinez - Rama samuel.
- Diego García Escobedo- Rama diego.

## Tematica

Nuestra tienda estara dedicada a la venta de ropa casual.

Las categorias iniciales seran:

- Camisetas.
- Sudaderas.
- Pantalones.

Cada producto tendra su propia talla, color y stock.

## Tecnologias

- Java 21.
- Spring Boot 3.5.6.
- Maven.
- Spring Web.
- Git y GitHub.
- Postman.

## Modelo

Categoria, Producto, Usuario, Carrito, LineaCarrito,
Pedido y LineaPedido.

Enumerados: Rol y EstadoPedido.
